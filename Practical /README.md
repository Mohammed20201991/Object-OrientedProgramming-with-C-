# Object-Oriented Programming with C++ – Practical

## Second Year – Artificial Intelligence dep. /CIT 

## Practical Course Description

This practical course provides hands-on programming experience with Object-Oriented Programming using C++.

Students are expected to have basic knowledge of:

* C++
* Structured programming
* Functions
* Arrays
* Pointers
* Structures
* File handling

The practical course focuses on solving programming problems using reusable and maintainable object-oriented solutions.

## Practical Objectives

By the end of the practical course, students should be able to:

1. Create classes and objects.
2. Implement constructors and destructors.
3. Apply encapsulation.
4. Design relationships between classes.
5. Use composition and aggregation.
6. Overload operators.
7. Implement inheritance.
8. Implement runtime polymorphism.
9. Create abstract classes.
10. Work with dynamic objects and memory.
11. Implement templates.
12. Handle exceptions.
13. Use STL containers and algorithms.
14. Build a complete OOP application.

## Lab Requirements

Students should have:

* C++ compiler with C++17 support
* Visual Studio, VS Code, or Code::Blocks
* Git (recommended)
* GitHub account (recommended)

## Lab Structure

Each laboratory should contain:

1. Learning Objectives
2. Short Theory
3. Demonstration
4. Guided Examples
5. Exercises
6. Challenge Problem
7. Homework
