# Final Project

## Objective

Develop a complete C++ application using Object-Oriented Programming principles.

## Project Requirements

Each project must include:

* At least 5 classes
* Encapsulation
* Constructors
* Composition or aggregation
* Inheritance
* Polymorphism
* Exception handling
* STL containers
* STL algorithms
* Appropriate class relationships
* Modular source code

## Project Development Stages

### Stage 1 – Problem Analysis

Students describe:

* Problem
* Users
* Requirements
* Main Operations

### Stage 2 – Class Identification

Identify:

* Classes
* Attributes
* Methods
* Class Relationships

### Stage 3 – UML Design

Create a UML class diagram showing the main classes, attributes, methods, and relationships.

### Stage 4 – Implementation

Implement the project using:

* `.h` files
* `.cpp` files
* `main.cpp`

### Stage 5 – Testing

Test the application with:

* Normal input
* Invalid input
* Boundary cases
* Exception cases

### Stage 6 – Presentation

Students should demonstrate:

1. Problem
2. UML Design
3. Classes
4. OOP Concepts
5. Program Execution
6. Challenges
7. Results
