# Lab 06 – Operator Overloading

## Objectives

* Understand operator overloading.
* Overload arithmetic operators.
* Overload comparison operators.

## Practice

Implement a `Complex` class with overloaded operators:

* `+`
* `-`
* `==`
* `!=`

## Exercises

Implement operator overloading for:

* `Time`
* `Date`
* `Matrix`
* `Student`

## Challenge

Create a `Matrix` class that supports:

* `+`
* `-`
* `*`
* `==`
