# Lab 03 – Constructors and Destructors

## Objectives

* Understand constructors.
* Use parameterized constructors.
* Use constructor overloading.
* Understand destructors.

## Practice

Create a `BankAccount` class with:

* Default Constructor
* Parameterized Constructor
* `deposit()`
* `withdraw()`
* `display()`

## Exercises

Create constructors for:

* `Student`
* `Product`
* `Book`
* `Employee`

## Challenge

Create a class that demonstrates the execution order of constructors and destructors.
