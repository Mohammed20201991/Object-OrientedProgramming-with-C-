
# Lab 01 – Introduction to OOP

## Objectives

* Understand the difference between structured programming and OOP.
* Identify objects and classes.
* Convert a simple procedural program into a class-based program.

## Practice

Create a `Student` class with the following:

### Attributes

* `ID`
* `Name`
* `Age`
* `GPA`

### Methods

* `setData()`
* `display()`

## Exercise

Create classes for:

* `Student`
* `Book`
* `Car`
* `Employee`

## Challenge

Convert an existing structured-programming application into an object-oriented design.
