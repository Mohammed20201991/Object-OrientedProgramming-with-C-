# Lab 07 – Inheritance

## Objectives

* Create base classes.
* Create derived classes.
* Understand Is-A relationships.

## Practice

Create the following inheritance hierarchy:

```text
Person
 |
 +--- Student
 |
 +--- Teacher
```

## Exercises

Implement the following hierarchy:

```text
Vehicle
 |
 +--- Car
 |
 +--- Bus
 |
 +--- Motorcycle
```

## Challenge

Create a university personnel hierarchy using inheritance.
