# Lab 18 – OOP Design and UML

## Objectives
Students learn how to design an object-oriented solution before writing code.

## Design Process
```text
Problem
   ↓
Identify Classes
   ↓
Identify Attributes
   ↓
Identify Methods
   ↓
Identify Relationships
   ↓
UML Diagram
   ↓
C++ Implementation
```

## Practice
Design a **Library Management System** using the following classes:
* `Library`
* `Book`
* `Member`
* `Librarian`

Students should create a **UML class diagram** showing the classes, their attributes, methods, and relationships before writing the C++ implementation.
