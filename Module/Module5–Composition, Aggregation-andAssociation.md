# Module 5 – Composition, Aggregation and Association

## Topics

* Has-A Relationship
* Is-A Relationship
* Composition
* Aggregation
* Association
* Object as a Data Member
* Relationships Between Classes

## Example

```text
Car
 |
 +---- Engine
 |
 +---- Wheel
 |
 +---- Driver
```

## Learning Outcome

Students will learn how objects and classes can be related to each other and when to use **composition** instead of **inheritance**.
