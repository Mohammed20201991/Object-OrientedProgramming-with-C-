# OOP Programming Project
## Individual Project Assignment

### Project Description

Each student must develop **an individual C++ project of their own choice** that demonstrates the practical application of Object-Oriented Programming (OOP) concepts discussed in class.

Students are free to choose their own project idea. The project may be related to student management, banking, healthcare, robotics, artificial intelligence, business management, or any other suitable application.

### Project Requirements

Your project must:

1. Be developed using C++.
2. Have a clear purpose and practical application.
3. Apply the OOP concepts discussed in class.
4. Include appropriate classes and objects.
5. Provide a functional program with a clear user interface.
6. Be your own work and demonstrate your understanding of the implemented concepts.

### Required OOP Concepts

Your project must demonstrate the following concepts:

- Classes and Objects
- Encapsulation
- Constructors and Destructors
- Inheritance
- Polymorphism
- Function Overloading
- Access Modifiers (`private`, `public`, and `protected`)

### Submission Requirements

1. Develop your project using C++.
2. Organize your source code properly.
3. Upload your complete project to **GitHub**.
4. Include a `README.md` file containing:
   - Project title and description.
   - Project objectives.
   - OOP concepts applied.
   - Instructions for compiling and running the program.
5. Submit your GitHub repository link.

### GitHub Submission

You can submit your project using either of the following methods:

- **Option 1:** Create your own GitHub repository, upload your project, and send me the repository link.
- **Option 2:** Create a GitHub repository and invite me as a contributor. Then send me the repository link.

Make sure your repository is accessible and contains all project files.

### Evaluation Criteria (10 Marks)

| Criteria | Marks |
|---|---:|
| Project functionality and implementation | 2 |
| Classes, objects, and encapsulation | 2 |
| Constructors, destructors, and function overloading | 1 |
| Inheritance and access modifiers | 2 |
| Polymorphism and virtual functions | 2 |
| Code organization and documentation | 1 |
| **Total** | **10** |

### Important Instructions

- Each student must choose **their own project idea**.
- Students must work individually.
- Projects must demonstrate the required OOP concepts.
- Students should be able to explain and demonstrate their code.
- Copying another student's project is not permitted.

**Submission:** Send your GitHub repository link. Ensure that the project is complete and accessible before submission.
