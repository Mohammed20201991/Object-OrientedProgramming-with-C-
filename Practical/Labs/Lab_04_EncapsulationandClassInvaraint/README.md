# Lab 04 – Encapsulation and Abstraction

## Objectives

* Protect class data.
* Use getters and setters.
* Validate input.
* Understand abstraction.

## Practice

Create a `BankAccount` class.

### Private Members

* `accountNumber`
* `ownerName`
* `balance`

### Public Methods

* `deposit()`
* `withdraw()`
* `getBalance()`
* `display()`

## Challenge

Implement validation to prevent:

* Negative deposits
* Negative balance
* Invalid account numbers
