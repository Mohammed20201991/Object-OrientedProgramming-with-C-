# Lab 08 – Multilevel and Multiple Inheritance

## Objectives

* Understand inheritance levels.
* Implement multilevel inheritance.
* Understand multiple inheritance.

## Practice

Create the following multilevel inheritance hierarchy:

```text
Person
  |
Student
  |
AIStudent
```

## Challenge

Create a system demonstrating multiple inheritance.

Explain:

* When multiple inheritance should be used.
* When multiple inheritance should be avoided.
