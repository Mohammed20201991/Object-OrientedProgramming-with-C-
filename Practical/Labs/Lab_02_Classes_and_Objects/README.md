# Lab 02 – Classes and Objects

## Objectives

* Create classes.
* Create multiple objects.
* Use `private` and `public` members.
* Define member functions.

## Practice

Create a `Rectangle` class with:

```cpp
class Rectangle
{
private:
    double width;
    double height;

public:
    double area();
    double perimeter();
};
```

## Exercises

Create classes for:

1. `Circle`
2. `Rectangle`
3. `Triangle`
4. `Employee`
5. `BankAccount`

## Challenge

Create a `Student` class that calculates:

* Total Marks
* Average
* Grade
