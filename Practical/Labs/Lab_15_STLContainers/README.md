# Lab 15 – STL Containers
## Objectives
Learn the most important STL containers and understand when to use each one.
## Vector
```cpp
vector<int> numbers;
```
## Map
```cpp
map<string, double> students;
```
## Stack
```cpp
stack<int> values;
```
## Queue
```cpp
queue<string> students;
```
## Exercises
Implement:
1. Student list using `vector`
2. Student GPA database using `map`
3. Browser history using `stack`
4. Waiting queue using `queue`
