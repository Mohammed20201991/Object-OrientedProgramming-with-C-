# Lab 12 – Dynamic Memory and Copying

## Objectives

* Create dynamic objects.
* Use `new` and `delete`.
* Understand shallow copying.
* Implement deep copying.

## Practice

Create a `DynamicArray` class with:

* `size`
* `data`

## Required

Implement:

* Constructor
* Destructor
* Copy Constructor

## Challenge

Demonstrate the difference between:

* Shallow Copy
* Deep Copy
