# Lab 05 – Composition and Aggregation

## Objectives

* Understand Has-A relationships.
* Implement composition.
* Implement aggregation.

## Practice

Create the following class relationship:

```text id="x4pn8d"
Car
 |
 +--- Engine
 |
 +--- Wheel
```

## Exercise

Create the following model:

```text id="m2rk9f"
University
 |
 +--- Department
       |
       +--- Student
```

## Challenge

Design a small university management model using at least three related classes.
